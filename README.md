# Mallorca Cycling

**Mallorca Cycling** és una aplicació web interactiva (PWA) dissenyada com a projecte final per a l'assignatura de **Tecnologia Multimèdia** de la **UIB** (Universitat de les Illes Balears). Ha estat desenvolupada per **Pau Antich** i **Jaume Ribas**.

## Què és aquesta pàgina?

Aquesta plataforma és la guia definitiva per explorar, conquerir i fer un seguiment dels millors segments ciclistes (ports de muntanya i rutes) al llarg de l'illa de Mallorca. Està pensada tant per a ciclistes locals com per a turistes que volen descobrir els reptes que ofereix l'illa, proporcionant informació detallada sobre cada pujada i permetent la integració amb les dades reals de l'usuari.

## Què hi conté?

L'aplicació inclou les següents funcionalitats i seccions principals:

- **Mapa Interactiu:** Una vista completa de Mallorca on els usuaris poden localitzar visualment tots els ports i rutes disponibles, utilitzant Google Maps.
- **Explorador de Segments:** Una secció on es llisten tots els ports ciclistes (com Sa Calobra, Puig Major, Coll de Sóller, etc.) amb un sistema complet de filtres. Es pot filtrar per:
  - Distància (km)
  - Desnivell (m)
  - Categoria de dificultat
- **Perfil d'Usuari i Integració amb Strava:** Els usuaris poden iniciar sessió amb el seu compte de **Strava**. Això els permet:
  - Veure els seus rècords personals (PR) en cada un dels ports de l'aplicació.
  - Veure els seus segments destacats (starred segments) directament des de Strava.
  - Consultar les seves estadístiques ciclistes anuals i recents (distància total, desnivell acumulat, sortides...).
- **Suport Multi-idioma:** L'aplicació està completament traduïda a tres idiomes: Català, Castellà i Anglès.
- **PWA (Progressive Web App):** L'aplicació està configurada com a PWA. Això significa que es pot instal·lar com una aplicació nativa als telèfons mòbils o ordinadors, i disposa d'un *Service Worker* que gestiona la memòria cau per oferir temps de càrrega ràpids i, fins i tot, funcionalitat parcial sense connexió a internet (offline).
